خروجی Base64 برای ساخت لینک سابسکریپشن. می‌توانید آن را دانلود و در همین سایت Netlify منتشر کنید.

          

          

            
            
          

        

      


      

        

          ❓ چطور وصل شوم؟
          
    
            
  1. اگر پروژه را روی Cloudflare Pages/Workers باز کرده‌اید، قالب ☁️ Cloudflare Worker را انتخاب کنید؛ آدرس، مسیر و UUID خودکار پر می‌شود و کانفیگ واقعاً به همین ورکر وصل می‌شود.
    2. 
            
  2. اگر سرور Xray روی VPS دارید، قالب VLESS + Reality را انتخاب و مشخصات سرورتان را وارد کنید.
    3. 
            
  3. روی گوشی: اپ v2rayNG (اندروید) یا Hiddify / Streisand (iOS) → گزینه Add config from QR / Clipboard.
    4. 
            
  4. روی کامپیوتر: v2rayN / Hiddify / Nekoray → درج لینک از کلیپ‌بورد یا وارد کردن فایل JSON.
    5. 
            
  5. سابسکریپشن روی Cloudflare: آدرس /sub را در کلاینت اضافه کنید. روی هاست استاتیک: فایل sub.txt را در ریشه سایت بگذارید و آدرس آن را وارد کنید.
    6. 
          

          
⚠️ Netlify فقط پنل سازنده کانفیگ را میزبانی می‌کند و پروکسی اجرا نمی‌کند. برای «کانفیگ وصل بدون VPS» از همین پروژه روی Cloudflare Pages/Workers استفاده کنید. کانفیگ‌های Worker از UDP پشتیبانی نمی‌کنند.
