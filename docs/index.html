🚀 باز کردن پنل

داخل پنل، قالب ☁️ Cloudflare Worker خودکار انتخاب می‌شود؛ فقط QR را اسکن کنید.

توکن من کجا می‌رود؟

توکن شما به رله متن‌باز MYX ارسال می‌شود تا از سمت سرور به API کلودفلر وصل شود؛ چون مرورگر به‌دلیل CORS اجازه تماس مستقیم با API کلودفلر را ندارد. رله هیچ توکنی را ذخیره یا لاگ نمی‌کند و توکن فقط در حافظه همان درخواست باقی می‌ماند.

چرا Account ID نمی‌خواهد؟

رله با خود توکن، اکانت متصل را از Cloudflare می‌خواند؛ به همین دلیل فقط توکن کافی است. اگر چند اکانت دارید، توکن را فقط برای اکانت موردنظر بسازید.

دسترسی توکن را چطور محدود کنم؟

در صفحه API Tokens، گزینه Create Custom Token را انتخاب کنید و فقط دو دسترسی Workers Scripts: Edit و Account Settings: Read را برای همان اکانت بدهید. بعد از ساخت پنل، توکن را Delete کنید.

اگر پنل با Error 1101 باز نشد چه کنم؟

روی بعضی اکانت‌ها دامنهٔ workers.dev از سمت Cloudflare مسدود یا قطع است و هیچ کدی این را درست نمی‌کند. دو راه‌حل: ۱) در داشبورد به Workers & Pages → نام Worker → Settings → Domains & Routes بروید و یک دامنهٔ اختصاصی وصل کنید، یا ۲) در همین فرم گزینهٔ Pages را انتخاب کنید.

اگر ساخت ناموفق بود چه کنم؟

مطمئن شوید توکن منقضی نشده و دسترسی‌های بالا را دارد. اگر خطای دسترسی گرفتید، یک‌بار وارد داشبورد Workers شوید تا زیردامنه workers.dev ساخته شود، سپس دوباره تلاش کنید.
