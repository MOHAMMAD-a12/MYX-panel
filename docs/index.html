بعد از Deploy چه چیزی می‌گیرید؟

یک پنل اختصاصی MYX panel با کانفیگ واقعی VLESS، QR Code و سابسکریپشن خودکار روی شبکه Cloudflare.

https://myx-panel.<account>.workers.dev.../sub   ← Subscription
توکن من کجا نگهداری می‌شود؟

توکن فقط در GitHub Secrets قرار می‌گیرد و هنگام اجرای Action مستقیماً به API رسمی Cloudflare فرستاده می‌شود. این صفحه هیچ فیلد دریافت توکنی ندارد و هیچ داده‌ای ذخیره یا رد‌وبدل نمی‌کند.

چرا توکن را داخل همین صفحه وارد نمی‌کنم؟

GitHub Pages کاملاً استاتیک است و API کلودفلر اجازه چنین فراخوانی مستقیمی از مرورگر (CORS) نمی‌دهد. استفاده از CORS Proxy عمومی هم امن نیست، چون صاحب Proxy به توکن دسترسی پیدا می‌کند. GitHub Actions روش امن و رسمی برای این اتوماسیون است.

برای نصب مجدد یا تغییر نام پنل چه کنم؟

دوباره همان Action را اجرا کنید. اگر نام Worker را تغییر دهید، یک پنل جدید با UUID تازه ساخته می‌شود؛ اگر نام قبلی را نگه دارید، همان Worker به‌روزرسانی می‌شود.
